# 东北家常菜 · 墙面菜单点菜系统

基于餐厅实拍墙面菜单构建的零依赖单页点菜 Web 应用（纯前端 HTML + SVG 精绘菜品插画）。

## 功能特点

- **全量菜品收录**：完整录入墙面 6 张菜单共 102 个可点菜品项（含特色菜、绿框主菜单、发光灯箱墙、门口凉菜主食竖牌及单品海报），其中 57 道字迹清晰的菜品附带准确标价，其余反光未标清项支持店内随手补记并本地保存。
- **专属高精度 SVG 菜品插画**：按真实器皿（铸铁板、双耳砂锅、不锈钢烤鱼盘、竹笼屉、大汤碗、青边白瓷盘）与食材特征分层绘制，支持点击放大查看详情及切换纯文字紧凑模式。
- **快捷检索与搭配统计**：支持菜名、墙面区域筛选与拼音首字母检索（如输入 `dsx` 检索地三鲜），实时汇总荤菜、水产、素菜与凉菜主食比例。
- **一键复制纯菜名（不含价格）**：支持“每行一菜”、“顿号单行”、“带序号”三种排版，自动剔除所有价格数字，可选是否保留多份数量（`×2`）及口味忌口备注。

## 使用与部署

1. **本地直接使用**：双击打开 `index.html` 即可在手机或电脑浏览器使用。
2. **GitHub Pages 在线访问**：上传至公开仓库后，进入仓库 `Settings` -> `Pages` -> `Build and deployment` 选择 `Deploy from a branch`（`main` 分支 `/ (root)` 目录），保存后即可获得手机随时可打开的在线点菜网址。
