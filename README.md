# 东北家常菜 · 墙面菜单点菜系统

基于餐厅墙面菜单构建的响应式点菜 Web 应用，全量配备统一布光实拍级美食摄影图（`images/*.webp`）。

## 核心特性

- **全墙 102 道菜品完整收录**：涵盖招牌硬菜、绿框家常主菜单、发光灯箱墙、门口凉菜汤主食及单品海报；57 道清晰标价菜品精准录入，未标清菜品支持店内点击随手补记并自动保存在本地浏览器。
- **全套实拍级高清美食摄影配图**：109 张统一深胡桃木桌面与 45° 自然暖光美食配图（含全部 102 道菜单菜品及米饭、大碴粥、馒头等快捷加点项），支持点击大图预览与一键切换无图紧凑列表。
- **极速检索与荤素搭配统计**：支持菜名关键词、墙面位置分区筛选及拼音首字母搜索（如输入 `dsx` 查找地三鲜），底部实时统计已选荤菜、水产、素菜与主食比例。
- **一键复制纯菜名（不含价格）**：支持“每行一菜”、“顿号单行”、“带序号”三种复制格式，自动剥离全部价格信息，可选附带多份数量（如 `×2`）及口味忌口备注。

## 部署与使用

1. **本地使用**：解压后直接用浏览器打开 `index.html` 即可（保持 `images/` 文件夹在同一目录）。
2. **GitHub Pages 在线点菜**：将仓库全部文件（`index.html`、`images/`、`README.md`、`.nojekyll`）上传至公开仓库后，在仓库 `Settings -> Pages` 选择 `main` 分支 `/ (root)` 保存，即可生成手机随时访问的在线点菜页面。
